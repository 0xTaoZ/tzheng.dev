Security posture

This site is designed as a static, low-attack-surface portfolio: no login area, no comment box, no payment flow, and no hidden admin panel on the public website.

This domain is routed through Cloudflare nameservers, giving the site an edge layer for HTTPS delivery, DNS protection, caching, and basic abuse filtering before traffic reaches the static site.

No tracking scriptsNo intentional analytics trackers or advertising pixels are added by this site.
No account systemVisitors do not create accounts, passwords, profiles, or session data here.
Static by designMost content is shipped as static HTML/CSS/JS, which keeps the public surface small.

Datenschutz / Privacy

This website does not use account registration, comments, payment processing, or tracking forms.

External links may lead to third-party services such as GitHub. Those services have their own privacy policies.

If you contact me by email, I will only use your message to reply.

No analytics cookies are intentionally placed by this static website. Hosting providers, DNS providers, or edge security services may process technical request data such as IP address, user agent, and request time for security, abuse prevention, and delivery.
